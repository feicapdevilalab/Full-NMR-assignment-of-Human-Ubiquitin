# Full-NMR-assignment-of-Human-Ubiquitin
Complete dataset used for the nearly full assignment of human ubiquitin in aqueous solution.

This repository includes:
1.	1H-15N HSQCa	NH-HN
2.	3D BH-HNCOb	N(i)H-H(i)N-C´(i-1)
3.	3D HN(CA)COb	(N(i)H-H(i)N-C´(i-1), N(i)H-H(i)N-C´(i))
4.	3D BH-HNCAb	(N(i)H-H(i)N-Cα(i-1), N(i)H-H(i)N-Cα (i))
5.	3D BH-HN(CO)CAb	N(i)H-H(i)N-Cα (i-1)
6.	3D CC(CO)NH-TOCSYc	N(i)H-H(i)N-C(i-1) all aliphatic side chain carbon resonances
7.	3D H(CC)H TOCSYd	C(i)-H(i)-H(i) (through one bond coupling of aliphatic resonances
8.	3D 1H-15N-TOCSY-HSQCe	N(i)H-H(i)N-all aliphatic side chain protons(i)
9.	3D CBCA(CO)NHb	(N(i)H-H(i)N- Cα(i-1) /Cβ(i-1), Nδ2-Hδ-Cα(i)/Cβ(i) for asparagine side chains, Nδ2-Hδ-Cβ(i)/Cγ(i) for glutamine side chains)
10.	HISQCf	Nε-Hε for arginine side chain
11.	H2(C)Ng	Nε-Hδ for arginine side chain
12.	H2CNCC(CO)NH-TOCSYh	Nε(i)-H(i) for arginine aliphatic side chain protons
13.	(HB)CB(CGCD)Hari	Cβ-Hδ for aromatic side chain
14.	(HB)CB(CGCE)HEi	Cβ-Hε for aromatic side chain
15.	(HB)CB(CGCC)Hai	Cβ-Har for all aromatic side chain protons
16.	His-H(C)Nj	(Nε2-Hε1, Nε2-Hδ2, Nδ1-Hδ1, Nδ1-Hδ2)
17.	3J HNCγk	(Cγ(i)-H(i)N)
18.	CT-1H-13C HSQC aromatics	(Cδ-Hδ, Cε-Hε, Cζ-Hζ)
19.	CCPNMR assignment project including all processed and assigned spectra.
